# Cyber Traffic Insight

## Overview
Cyber Traffic Insight is a Data Science project focused on analyzing network traffic to understand normal and unusual traffic patterns for defensive cybersecurity monitoring.

## Objectives
- Understand and inspect network traffic datasets.
- Identify missing values, duplicate records, inconsistent labels, and extreme values.
- Perform Exploratory Data Analysis (EDA).
- Visualize protocol distributions and hourly traffic patterns.
- Compare traffic across network zones, port categories, and host groups.
- Perform feature engineering and categorical encoding.
- Prepare datasets for further analysis using Microsoft Excel.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Microsoft Excel

## Dataset Files
The project uses five related CSV datasets:

- `flows.csv` — Network flow information.
- `hosts.csv` — Host groups and network zones.
- `sessions.csv` — Session information and port categories.
- `labels.csv` — Normal and unusual traffic labels.
- `calendar.csv` — Hour, weekday, and maintenance-window information.

**Note:** The datasets used for this project are synthetic practice data created for educational analysis. They do not represent actual network traffic or confirmed cyber incidents.

## Project Workflow
1. Dataset loading and inspection.
2. Data-quality assessment.
3. Data cleaning and integration.
4. Exploratory Data Analysis and visualization.
5. Feature engineering and categorical encoding.
6. Feature relationship analysis.
7. Export of datasets and visualizations for Excel analysis.

## Deliverables
- Google Colab notebook.
- Cleaned and integrated traffic dataset.
- Protocol summary and visualization.
- Prepared data for Excel analysis.
